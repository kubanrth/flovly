# UI-API — kontrakt prymitywów `components/ui/*` (redesign v5)

Źródło wyglądu: `docs/redesign/v5/A1-design-system.dc.html` (+ `A1-design-system-mobile`), PNG w `docs/redesign/v5/png/`. Tokeny: `app/globals.css` (`:root` + `@theme`). **Zero literałów hex w komponentach** (wyjątek: `icons.tsx`, `brand/mark.tsx`) — używaj utility Tailwind mapowanych na tokeny: `bg-background|card|popover|canvas|muted|selected|row-hover|table-header`, `text-foreground|muted-foreground|fg-*`, `border-border|input-border`, `bg-orange-*`, `bg-n-*`, `text-success-text|warning-text|danger-text|info-text`, `bg-chip-<hue>-bg text-chip-<hue>-fg` (hue: gray orange red yellow green teal blue indigo purple pink brown black), `shadow-e1|e2`, `rounded-sm(4)|md(6)|lg(8)|xl(12)`, `text-2xs(11)|xs(12)|sm(13)|base(14)|md(16)|lg(20)|xl(24)|2xl(32)`, `font-mono`.

Reguły: Inter 13/20 body; eyebrow = klasa `.eyebrow`; kontrolki „on" = `bg-control-on` (`#1C1A17`), NIE pomarańcz; pomarańcz tylko primary button / focus / aktywna nawigacja / zaznaczony wiersz / linki; focus = `focus-visible:shadow-[var(--focus)]` (globalnie już w base); motion 100–220ms, tylko opacity/transform; brak `transition-all`, brak gradientów, brak `dark:`. Wszystkie prymitywy na `@base-ui/react` gdy istnieje odpowiednik; warianty przez `class-variance-authority`; `cn()` z `@/lib/utils`.

Zachowaj kompatybilność eksportów istniejących plików (używane w aplikacji): `dialog.tsx`, `sheet.tsx`, `skeleton.tsx`, `date-time-picker.tsx`, `empty-state.tsx`, `searchable-dropdown.tsx`, `checkbox.tsx`, `portal-dropdown.tsx`, `editable-title.tsx`, `button.tsx` — te same nazwy eksportów i propsy (możesz dodać nowe propsy), tylko nowy wygląd.
