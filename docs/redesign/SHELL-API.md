# SHELL-API — kontrakt komponentów shell'a (F1)

Makiety: `docs/redesign/v5/A2-app-shell.dc.html` (+ `-pasek-ikon`, `-mobile`), `A3-menu-i-skroty.dc.html`; PNG w `v5/png/`. Prymitywy: `components/ui/*` wg `docs/redesign/UI-API.md` (`Button`, `Menu*`, `Dialog*`, `Tooltip`, `Kbd`, `Avatar`, `Badge`, `Segmented`, `Tabs`, `Checkbox`, `Switch`, `icons.tsx`).

Wspólne: preferencje w `localStorage` z prefiksem `ui:` (`ui:sidebar` = "expanded"|"rail", `ui:sidebar-items` = JSON `{hidden: string[]}`, `ui:density` = "compact"|"comfortable"|"spacious", `ui:starred` = JSON `[{type:"board"|"task", id, label, href}]`, `ui:recent` = JSON jw. max 5). Gęstość aplikowana przez `document.documentElement.dataset.density` (CSS `[data-density]` w globals ustawia `--row-h`). Hook `hooks/use-ui-pref.ts`: `useUiPref<T>(key, fallback)` → `[value, set]` z SSR-safe odczytem (efekt) i `storage` event sync. Haki testowe `data-ui="…"` dokładnie jak w `.wayfinder/MAP.md` D21.
